# hslaugi.github.io

Personal academic and research portfolio for Hemshankar Laugi.

## Publishing
Upload the **contents of this folder** to the root of the GitHub repository named:

`hslaugi.github.io`

Then enable GitHub Pages from the `main` branch and `/ (root)` folder.

## CV updates
To update the CV without editing the website code, replace the file in the repository root with a new PDF using the exact filename:

`Laugi_Hemshankar_CV.pdf`

The website will automatically link to the new version.

## Optional images
Add any of the following files under `assets/images/` and they will appear automatically:

- `profile.jpg`
- `alzheimers-project-schematic.jpg`
- `facial-asymmetry.jpg`
- `densenext.jpg`
- `transfer-learning.jpg`
- `cerebral-palsy-mri.jpg`

If an optional image is not present, the website remains functional without it.

## IEEE EMBS logo
The Leadership section loads the official IEEE EMBS logo from the EMBS website. If the external logo cannot load, the page automatically hides the image while preserving the leadership content.
